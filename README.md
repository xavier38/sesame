# Sesame

Tous vos clouds dans une application Mac. Choisissez les dossiers à synchroniser entre vos comptes cloud, vos NAS et votre ordinateur.

- **Mac** : disponible pour Apple Silicon, macOS 13 ou plus récent. [Installation](https://xavier38.github.io/sesame/installation.html).

[Site officiel](https://xavier38.github.io/sesame/) · [Téléchargement Mac](https://github.com/xavier38/sesame/releases/latest) · [Confidentialité](https://xavier38.github.io/sesame/confidentialite.html)

Application gratuite, en sept langues. Ce dépôt public contient le site et les versions distribuées ; le code source reste privé.
