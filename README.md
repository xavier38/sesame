# Sesame

Tous vos clouds dans une application multi-OS. Choisissez les dossiers à synchroniser entre vos comptes cloud, vos NAS et votre ordinateur.

- **Mac** : disponible pour Apple Silicon, macOS 13 ou plus récent. [Installation](https://xavier38.github.io/sesame/installation.html).
- **Linux** : disponible pour Debian 12 et Ubuntu 22.04 ou plus récents. [Installation](https://xavier38.github.io/sesame/linux.html).
- **Windows** : en cours de validation, pas encore disponible.

[Site officiel](https://xavier38.github.io/sesame/) · [Téléchargements Mac et Linux](https://github.com/xavier38/sesame/releases/latest) · [Confidentialité](https://xavier38.github.io/sesame/confidentialite.html)

Application gratuite, en sept langues. Ce dépôt public contient le site et les versions distribuées ; le code source reste privé.
